## 🌐 VISIÓN GENERAL
**Agency Amatrix** es una plataforma de servicios de élite diseñada para conectar profesionales verificados con clientes que buscan soluciones inmediatas. Inspirada en la eficiencia de sistemas como InDriver, pero potenciada con **Inteligencia Artificial (Gemini AI Studio)** para la gestión y aprendizaje técnico.

---

## 🛠️ CARACTERÍSTICAS PRINCIPALES

* **⚡ Interfaz de Alto Impacto**: Diseño neón optimizado para **Redmi Note 14** y dispositivos móviles (Mobile-First).
* **🤖 Academia Amatrix**: Sistema de formación nivel por nivel integrado con IA para capacitar a nuevos profesionales.
* **📍 Seguimiento en Tiempo Real**: Visualización estilo Uber del progreso y llegada del profesional al domicilio.
* **🛡️ Sistema Escrow**: Seguridad en los pagos. El dinero se libera solo cuando el servicio se completa con éxito.
* **🧠 Motor de IA (Gemini)**: Consultoría técnica 24/7 para profesionales en campo mediante archivos `.ts` personalizados.

---

## 📂 ESTRUCTURA DEL PROYECTO (Tech Stack)

Este repositorio contiene la transición de una web estática a una **Web App Profesional**:

* **Frontend**: React + TypeScript (`.tsx`)
* **Estilos**: Tailwind CSS (Configurado para evitar desbordamientos en móvil)
* **Lógica de IA**: Gemini AI Service (`geminiService.ts`)
* **Despliegue**: Vercel (Optimización de Build automática)

## 🚀 CÓMO CONTINUAR EL DESARROLLO

1.  **Clonar el repositorio**:
    ```bash
    git clone [https://github.com/tu-usuario/agency-amatrix.git](https://github.com/tu-usuario/agency-amatrix.git)
    ```
2.  **Instalar dependencias** (Requiere Node.js):
    ```bash
    npm install
    ```
3.  **Configurar Variables de Entorno**:
    Añade tu `GEMINI_API_KEY` en el archivo de configuración para activar la Academia IA.
